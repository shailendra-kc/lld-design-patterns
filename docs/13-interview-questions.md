# 13. LLD Interview Questions

## Fundamentals

1. What is the difference between HLD and LLD?
2. How do you identify classes from requirements?
3. What is the difference between an entity and a value object?
4. Why is composition usually preferred over inheritance?
5. What are cohesion and coupling?
6. How do you protect domain invariants?
7. What is an anemic domain model?

## SOLID

1. Explain each SOLID principle with a violation.
2. How is SRP different from “one method per class”?
3. Give a real LSP violation.
4. When does an interface violate ISP?
5. How does dependency injection support DIP?

## Patterns

1. Strategy vs State?
2. Adapter vs Facade?
3. Decorator vs Proxy?
4. Factory vs Abstract Factory?
5. Builder vs telescoping constructor?
6. Observer vs message broker?
7. Command pattern use in job schedulers?
8. Why can Singleton be problematic?
9. When would you use Chain of Responsibility?
10. Which patterns are commonly used by Spring?

- Design a parking lot.

## Strong interview answer structure

1. State assumptions.
2. List use cases.
3. Identify core entities.
4. Define important interfaces.
5. Draw class relationships.
6. Walk through one main sequence.
7. Explain invariants.
8. Discuss concurrency and persistence.
9. Explain patterns and why they fit.
10. Mention trade-offs and extensions.
