# 14. Seven-Day LLD Revision Plan

## Day 1 — Fundamentals

- HLD vs LLD
- Entities and value objects
- Cohesion, coupling, encapsulation
- UML class and sequence diagrams

## Day 2 — SOLID

- Learn every principle
- Write one violation and refactoring for each
- Practice composition over inheritance

## Day 3 — Creational and Structural Patterns

- Factory, Abstract Factory, Builder, Singleton
- Adapter, Decorator, Facade, Proxy, Composite

## Day 4 — Behavioral Patterns

- Strategy, Observer, Command, State
- Chain of Responsibility and Template Method
- Compare similar patterns

## Day 5 — Parking Lot and Elevator

- Clarify requirements
- Draw UML
- Implement core domain logic
- Explain concurrency

## Day 6 — Splitwise and BookMyShow

- Money modeling
- Strategy pattern
- Seat locking and double-booking prevention
- State transitions

## Day 7 — Mock interview

- Solve one unseen design in 45–60 minutes
- Explain decisions aloud
- Add tests
- Review trade-offs and extensions
